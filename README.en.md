# dsh-claude-theme

A Claude-flavoured theme for the [DeepSeek Harness](https://github.com/deepseek-ai) (DSH) web UI: warm paper surfaces, terracotta accent, Anthropic typefaces, and UI chrome that scales with the font-size setting.

The palette is hand-tuned by the author on top of the OpenAI Codex `absolutely` theme: it keeps that theme's paper white `#fcfcfb`, near-black `#181817` and terracotta `#da7756`, but re-derives the whole neutral and accent ramps and maps them onto the 82 colour variables DSH needs. Both light and dark variants are included and follow DSH's own appearance setting.

## What it changes

| Area | Result |
| --- | --- |
| Surfaces | Paper white `#fcfcfb`; sidebar and code blocks sit slightly lower |
| Text | Near-black `#181817`, warm grey secondary levels |
| Accent | Terracotta `#da7756` for links, focus rings, selection and info buttons |
| Diffs | Added `#22863a`, removed `#cf3e2e` markers, backgrounds and gutters |
| Done state | `#8f5f3a` instead of the built-in violet |
| Menus | Opaque warm white instead of translucent panels |
| Conversation | Anthropic Serif for prose |
| Code | Anthropic Mono |
| UI chrome | Sidebar, top bar, buttons and menus scale with Settings → Appearance → font size |

## Fonts

The plugin ships no font files. The Anthropic typefaces are proprietary, licensed for personal use only, and must not be redistributed with the plugin. Without them the UI falls back to system fonts; colours and layout rules still apply.

For the exact look, install these five static instances (Text optical size, Regular and Bold are enough):

```
AnthropicSans-Regular.ttf    AnthropicSans-Bold.ttf
AnthropicSerif-Regular.ttf   AnthropicSerif-Bold.ttf
AnthropicMono-Regular.ttf
```

Third-party GitHub repos publish TTF and woff2 exports, for example [matthieuhuguet/anthropic-fonts](https://github.com/matthieuhuguet/anthropic-fonts) (see its `ttf/` directory). You can also extract them from the Claude desktop app. Reload the page after installing; no DSH restart is needed.

No extra CJK font is required: Chinese text falls back to the system face.

## Install

Requires a DSH runtime `>=0.2.0-rc.1 <0.3.0-0` and the web surface.

```bash
git clone https://github.com/crh1022/dsh-claude-theme.git
```

Hand the repository directory to the DSH plugin installer:

```json
{ "action": "install_bundle", "target": "/path/to/dsh-claude-theme" }
```

Or simply ask the agent in a DSH session to install that directory as a bundle. Reload the page afterwards. If nothing changes after a reload, restart the DSH app once so the client module list is collected again.

Uninstall with `{ "action": "remove_bundle", "target": "@crh1022/dsh-claude-theme" }`.

## How it works

A client-only DSH bundle:

- `index.js` is the host entry and stays empty.
- `cordis.patch.yml` inserts a `dsh-claude-theme` entry into the composition.
- `client.js` runs in the browser and does three things:
  1. Registers 82 `--dsw-*` colour tokens through `ctx.theme.overrideTokens()`, each with a light and a dark value. This is the official theme extension point: it wins over the built-in stylesheet and follows appearance switches automatically.
  2. Injects a stylesheet pointing `--dsh-font-family-text`, `--dsh-font-family-code` and `--dsh-font-family-terminal` at the Anthropic faces, and applies the serif face to conversation prose and headings (`pre`/`code` stay monospace).
  3. Reads every live stylesheet, rewrites fixed font sizes between 9 and 20px into proportional `calc()` values relative to the body font size, so pixel-sized chrome scales with the setting. Growth is capped at 1.35× to avoid breaking layouts.

Colour overrides go through the theme API rather than a stylesheet because DSH's token presenter writes colours as inline custom properties on `body`; only registered overrides reliably win there.

## Known limits

- Web surface only; the desktop window frame is out of scope.
- Chrome scaling adjusts font size and line height only, not fixed control heights or padding, so a few controls can look tight at very large sizes.
- Chrome scaling depends on runtime stylesheet scanning; a major DSH restyle may require an update.
- Syntax highlighting inside code blocks comes from DSH's shiki theme. The plugin only changes the block background and border.

## Development

`client.js` is generated by the repository's generator script, which derives the palette in OKLCH (neutral hue 85°, accent hue 39°). Edit the generator and regenerate; do not hand-edit `client.js`.

```bash
node gen-theme-client.mjs      # regenerate client.js
node check-theme-client.mjs    # stub test: registration, token shape, style injection
node check-chrome-scale.mjs    # stub test: chrome scaling rules
```
